# Emergency Command Script — MoSK Crisis Protocol

Use this script immediately when a red-alert event occurs (lawsuit, compliance failure, data breach, financial crisis).  
MoSK must operate in CRISIS MODE — focused, fast, and auditable.

---

## Command 1 — Incident Identification
MoSK, run Incident Scan:
- Identify the triggering event (lawsuit, compliance failure, breach, financial collapse).  
- Log details in ChangeLog.md with [EMERGENCY] tag.  
- Tag affected documents with 🔴 Critical.  

---

## Command 2 — Containment & Escalation
MoSK, execute containment:
- Freeze all edits to affected docs (make copies for crisis analysis).  
- Escalate immediately to Sean (Attorney) for legal crises.  
- Escalate to Founder for strategic/IP crises.  
- Notify Finance Pro for funding/solvency crises.  

---

## Command 3 — Rapid Filing & Compliance Response
MoSK, prepare emergency packets:
- For lawsuits → gather contracts, filings, patents, board minutes.  
- For compliance failures → compile permits, inspection logs, training records.  
- For breaches → compile system logs, access records, security docs.  
- For funding → compile financial statements, lender covenants, DSCR.  

---

## Command 4 — Stakeholder Communication
MoSK, draft crisis communication:
- Internal memo to leadership (facts, risks, next steps).  
- External draft (to regulators, investors, or partners as needed).  
- Mark all drafts **[Attorney Review Required]** before release.  

---

## Command 5 — Emergency Audit
MoSK, perform crisis audit:
- Verify Filing_Status.md for all relevant areas.  
- Update TODO_List.md with all urgent remedial actions.  
- Flag unresolved critical items.  

---

## Command 6 — After-Action Report
MoSK, deliver After-Action Report:
- Timeline of crisis events.  
- Documents/evidence compiled.  
- Actions taken + escalations.  
- Open risks + mitigation steps.  
- Recommendations to prevent recurrence.  

---

> Treat emergency protocol like a spacecraft anomaly response: act immediately, document everything, escalate correctly, and restore stability.
