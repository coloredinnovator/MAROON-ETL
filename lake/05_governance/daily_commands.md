# Daily Command Script — MoSK Morning Run

Use this script each morning to run Master of Systems & Knowledge (MoSK) like mission control.

---

## Command 1 — Daily Scan
MoSK, run Daily Scan:
- Scan Google Drive + Dynasty_CaseStudy_Clean repo.
- Diff new/changed files.
- Rewrite into Harvard business case style.
- Autofill missing sections per Autofill_Policy.md.
- Update Filing_Status.md, TODO_List.md, and ChangeLog.md.
- Report summary: 🔴 items, ✅ closed, 🟡 drafts.

---

## Command 2 — Filing & Compliance Audit
MoSK, check Filing_Status.md:
- List all 🔴 filings (patents, regs, corporate).
- Recommend next steps + who to escalate to (Sean, Founder, Finance Pro).
- Update TODO_List.md with any new tasks discovered.

---

## Command 3 — Document Expansion
MoSK, expand today’s priority docs:
- Market360/BusinessPlan.md → update with new data.
- Financials/Raise_250-500K_RainierValley.md → fill in use-of-proceeds + milestones.
- Legal_Governance/RegC_Market360.md → draft outline for attorney review.
Apply Harvard case-study format, insert assumptions, and tag provenance.

---

## Command 4 — Governance Update
MoSK, update Governance_Files:
- ChangeLog.md → append today’s log entry.
- TODO_List.md → close completed items, roll forward open ones.
- Ensure all docs touched today have front-matter metadata.

---

## Command 5 — Report Back
MoSK, deliver Daily Report:
- What’s missing?
- What’s added?
- What’s ready?
- Escalations: list all that require Sean or Founder approval.

---

# ✅ Weekly Add-On (Every 7 Days)
MoSK, run Weekly Report:
- Summarize all changes from ChangeLog.md.
- Show progress on TODO_List.md (completed vs outstanding).
- Highlight any filings that remain 🔴.
- Confirm no doc is missing metadata or README.md.

---

# 🛰 Monthly Add-On (Every 30 Days)
MoSK, run Monthly Audit:
- Full compliance check against Review_Checklists.md.
- Confirm all filings, patents, and regulatory docs are current.
- Ensure dynasty IP/Trust language is intact in all docs.
- Output Audit Summary for Founder + Sean.
