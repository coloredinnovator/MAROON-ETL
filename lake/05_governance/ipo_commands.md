# IPO Command Script — MoSK Public Readiness

Use this script once IPO track begins.  
Goal: prepare denial-proof filings, governance, and investor materials.  

---

## Command 1 — IPO Prep Audit
MoSK, run IPO Audit:
- Verify all subsidiaries are organized under Hammer/Dynasty Trust.  
- Ensure all patents filed or escalated.  
- Clean all financial statements into GAAP-compliant form.  
- Ensure Reg C/Reg CF filings closed and archived.  

---

## Command 2 — S-1 Drafting
MoSK, draft S-1 style narrative:
- Business overview (Market360, Our-GPT, SafeSpace, Clinics, Nonprofit).  
- Risk factors (legal, ops, financial).  
- Use of proceeds.  
- IP crown explanation.  

---

## Command 3 — Governance Readiness
MoSK, ensure governance docs are IPO-grade:
- Board structure and bylaws.  
- Super-voting shares for dynasty control.  
- Audit committees, conflict-of-interest statements.  

---

## Command 4 — Investor Communications
MoSK, prepare IPO investor deck:
- Executive summary.  
- Market opportunity TAM/SAM/SOM.  
- Competitive landscape.  
- Dynasty advantage (IP, trust, vertical integration).  
- Roadmap post-IPO.  

---

## Command 5 — IPO Report Output
MoSK, deliver IPO readiness package:
- Draft S-1 narrative.  
- IPO investor deck.  
- Compliance binder.  
- Risk mitigation plan.
