# Weekly Command Script — MoSK Mission Debrief

Use this script every 7 days to run Master of Systems & Knowledge (MoSK) like NASA’s end-of-week mission report.

---

## Command 1 — Weekly Scan & Summary
MoSK, run Weekly Report:
- Summarize all changes from ChangeLog.md for the past 7 days.
- Show progress on TODO_List.md (✅ completed vs 🔴 outstanding).
- Highlight any filings that remain 🔴 (patents, regs, corporate).
- Confirm no document is missing metadata or README.md.

---

## Command 2 — Filing Deep Dive
MoSK, audit Filing_Status.md:
- Re-check every item tagged 🟡 Draft or 🔴 Not Started.
- Provide next steps + responsible party (Sean, Founder, Finance Pro).
- Update TODO_List.md with escalations or deadlines.

---

## Command 3 — Subsidiary Health Check
MoSK, report subsidiary status:
- Market360 → BusinessPlan, Financial_Model, Raise docs.  
- Our-GPT → Product_Vision, AI_Patents, Data_Strategy.  
- SafeSpace → Community_Model, Impact_Framework.  
- Clinics_Sherie → Operations, Compliance.  
- Nonprofit_SeanED → Mission, Governance, Funding_Plan.  

Each: note what’s complete, what’s draft, what’s missing.

---

## Command 4 — Governance Hygiene
MoSK, validate Governance_Files:
- Ensure Operating_Model.md matches current cadence.  
- Ensure Autofill_Policy.md is followed (no blanks).  
- Ensure Review_Checklists.md were applied for all docs marked ✅.  
- Confirm ChangeLog.md has daily entries with no gaps.

---

## Command 5 — Weekly Debrief Output
MoSK, deliver Weekly Debrief Report:
- Summary of the week’s accomplishments.  
- Open risks (legal, finance, ops).  
- New opportunities discovered.  
- Escalation list for Sean & Founder.  
- Recommendations for next week’s High Priority tasks.

---

> Treat this like a mission debrief: precise, complete, and ready for hand-off to Founder and Attorney.
